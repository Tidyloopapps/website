How to split Shopify orders by vendor for dropshipping

Updated October 29, 2026

If some products ship from your own stock and others ship from a supplier, each order needs to be divided so the supplier only sees their items and your team only packs yours.

What Shopify does on its own

  • If the supplier's products are stocked at a separate location (or a fulfillment service), Shopify creates a separate fulfillment group for them automatically.
  • If they share your location, Shopify keeps everything in one fulfillment group, and you separate it by hand.
  • Shopify Flow can't split a fulfillment by vendor. It can react after a split happens, but it has no split action.

Splitting by vendor automatically

Make sure the Vendor field is set on each supplier product. Then use a rule such as "When an item is from the vendor Northwind Supply, ship it separately." Tidyloop Split applies that rule to every new order, inside the same order, so you don't create duplicate orders or refunds.

Good practice

  • Keep vendor names spelled exactly the same on every product.
  • Combine with a tag rule for items that need extra work, such as engraving.
  • Check the first few orders on the order page to confirm each supplier's items sit in their own group.
