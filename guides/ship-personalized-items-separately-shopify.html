How to ship personalized and made-to-order items separately in Shopify

Updated November 25, 2026

When an order mixes a stock item with something you engrave, print or make by hand, the stock item is ready today and the custom piece is ready next week. Customers usually prefer to get the ready part now. The goal is two shipments inside one order, with no second order and no refund.

What Shopify does on its own

  • Shopify puts every item from the same location into one fulfillment group, so the custom item and the stock item sit together.
  • You can split them by hand: on the order page, use Fulfill items for just the ready items, or place a hold on the custom item from the order page and fulfill the rest.
  • Shopify Flow can react to new orders and place holds, but it has no action that separates certain items into their own group first.

Doing this by hand is fine a few times a week. On every order it gets slow, and a forgotten hold means a late package.

Doing it automatically

  1. Give every custom product the same product tag, for example personalized or made-to-order.
  2. Add a rule: "When an item has the tag personalized, ship it separately."
  3. Optional: hold the custom item for a set number of days after each order (for example 5 days for your workshop), so it doesn't show as ready to ship before it is made.

Tidyloop Split applies that rule to each new order inside the same order. Stock items stay ready to ship; the custom item gets its own shipment, and if you chose a hold, it is released automatically after the number of days you set. You can release it early from the order page or from the app's Activity page. Holds are on the Pro plan; "ship separately" works on every plan.

Good practice

  • Tag the product, not the order, so every future order is covered.
  • Tell customers at checkout that custom items ship separately, so a second tracking email isn't a surprise.
  • In Settings → Shipping and delivery, check how you charge shipping on split orders; the split itself doesn't change what the customer paid.
  • For several tags (engraved, monogram, custom-size), list them in one rule, separated by commas.
