How to create a glossary in Confluence Cloud

Updated October 30, 2026

Every team builds up its own language: product names, acronyms, process terms. New hires and other teams lose time guessing what "CAB", "DoD" or "P1" means. A glossary fixes that, but only if people can find a definition at the moment they need it.

1. One glossary page

  1. Create a page called Glossary at the top of the space.
  2. Add a table with columns Term, Definition and Also called, sorted A–Z.
  3. Link to it from the space overview and pin it in the sidebar.

Quick to start. The weak points: readers have to leave the page they're on, the table gets long, and there's no way to see which terms a page uses.

2. Reusable definitions with excerpts

Put each definition in an Excerpt on the glossary page (or one small page per term), then use Insert excerpt wherever the definition should appear. When the definition changes, every page that includes it updates. This works well for a handful of key terms but becomes hard to manage beyond a few dozen.

3. Labels for discovery

Add a label such as glossary-sla to pages that explain a concept, and a Content by label list on the glossary page. Good for linking to longer explanations, not for quick definitions.

4. A glossary app

Marketplace glossary apps keep terms in one managed list and show definitions on the page where the term appears. Things to check before you install one:

  • Does it need a browser extension? Some apps only highlight terms in page text if every reader installs an extension, which many companies don't allow.
  • Speed. Try it on a long page; some apps slow pages down.
  • Import. Make sure a CSV from Excel or Google Sheets imports cleanly and tells you which rows failed.
  • Space vs. site terms. The same word can mean different things to different teams.
  • Where data is stored. Apps marked "Runs on Atlassian" keep data in Atlassian's cloud.

We're building one that shows the glossary terms a page uses from a button in the page header, with no extension: Glossary by Tidyloop Apps (coming to the Atlassian Marketplace).

Keeping a glossary useful

  • Write definitions in one or two plain sentences. Link to a full page for anything longer.
  • Record abbreviations with their exact capitals, so "SLA" and "sla" aren't confused.
  • Give the glossary an owner and review it each quarter.
  • When someone asks "what does X mean?" in chat, add X to the glossary.
